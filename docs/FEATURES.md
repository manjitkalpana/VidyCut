# Feature checklist

**Implemented** means there is executable application logic and an accessible workflow. It is not a claim of exhaustive device testing. **Partial** identifies an implemented subset. **Dependency** means a real adapter/backend is present but requires configuration. **Architecture** means a typed/validated extension point without a completed end-user workflow. **Not implemented** means the requested capability is absent. The separate QA record states what was actually tested.

All implemented editing and export features are unlocked and free. There is no watermark, subscription, premium badge, trial, or account-based resolution limit.

## Remaining work before the original full scope is satisfied

Complete frame-addressable animated GIF import, continuous speed curves, per-word captions, advanced grading/LUTs, independent pitch and streamed audio, full media cloud sync, full admin management, nested/multicam editing, true tracking/reframing/model workflows, alpha video export and the remaining mobile gestures. Validate secure WebCodecs, real auth/storage/worker flows, offline recovery and long projects on target devices. The current delivery should not be represented as complete CapCut-equivalent or production-audited software.

Portable ZIP backups include project metadata and all source media, validate checksums and media signatures, and restore atomically with fresh IDs. Proxies and uploaded font files are excluded. Unmodified VidyCut ZIPs up to the 2 GB browser budget are accepted. Keyframe values are retained at slice boundaries; slicing within nonlinear easing may alter the curve shape.
